# Create default cause-specific configurations

Returns a named list of `mort_config` objects for the standard UK
disease groups (all-causes, 9 diseases, and residual).

## Usage

``` r
default_configs(...)
```

## Arguments

- ...:

  Additional overrides passed to each
  [`mort_config()`](https://kalleEF.github.io/mortensor/reference/mort_config.md).

## Value

Named list of `mort_config` objects.
