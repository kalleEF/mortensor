# Gompertz extrapolation: log-linear in age

Gompertz extrapolation: log-linear in age

## Usage

``` r
extrapolate_gompertz(anchor_mx, anchor_ages, extrap_ages)
```

## Arguments

- anchor_mx:

  Numeric vector of mortality rates at anchor ages.

- anchor_ages:

  Numeric vector of anchor ages.

- extrap_ages:

  Numeric vector of ages to extrapolate to.

## Value

Numeric vector of extrapolated mortality rates.
