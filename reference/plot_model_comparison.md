# Bar chart of model MASE scores

Bar chart of model MASE scores

## Usage

``` r
plot_model_comparison(comp_dt, output_dir, cause_label, cause_short)
```

## Arguments

- comp_dt:

  data.table from
  [`compare_models()`](https://kalleEF.github.io/mortensor/reference/compare_models.md).

- output_dir:

  Output directory.

- cause_label:

  Full cause name.

- cause_short:

  Short cause key.
