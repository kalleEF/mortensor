# Negative log-score for Gaussian predictive distribution

Negative log-score for Gaussian predictive distribution

## Usage

``` r
compute_log_score_gaussian(obs, mu, sigma)
```

## Arguments

- obs:

  Numeric vector of observations.

- mu:

  Numeric vector of predictive means.

- sigma:

  Numeric vector of predictive standard deviations.

## Value

Scalar mean negative log-score.
