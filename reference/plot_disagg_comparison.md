# Disaggregation method comparison plot

Disaggregation method comparison plot

## Usage

``` r
plot_disagg_comparison(
  mx_grouped,
  age_starts,
  target_ages,
  output_dir,
  cause_short,
  width = 5
)
```

## Arguments

- mx_grouped:

  Grouped rates vector.

- age_starts:

  Age-group starts.

- target_ages:

  Single-year target ages.

- output_dir, cause_short:

  Standard plot params.

- width:

  Age-group width.
